# Adresses des snacks à Bruxelles (2022)

Les noms et adresses des snacks (pita-durum) à Bruxelles

## Usage

``` r
snacks
```

## Format

### `snacks`

Un data frame avec 484 lignes et 4 colonnes :

- nom:

  Le nom du snack

- rue:

  La rue à laquelle est situé le snack

- num:

  Le numéro de la rue

- code_postal:

  Le code postal de l'adresse
