# phaco_setup_data : Téléchargement et installation des données pour géocoder

Cette fonction permet d'installer sur l'ordinateur les fichiers
nécessaires pour le geocodage des adresses.

## Usage

``` r
phaco_setup_data(path_data = NULL)
```

## Arguments

- path_data:

  Chemin absolu vers le dossier où se trouve le données. Par défaut
  data_path = NULL et phacochr trouve le dossier d'installation choisi
  par défaut.

## Examples

``` r
if (FALSE) { # \dontrun{
phaco_setup_data()
} # }
```
